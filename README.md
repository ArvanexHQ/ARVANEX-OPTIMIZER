# 🚀 ARVANEX OS ULTRA

أداة احترافية صممتها لتعديل وتخفيف ويندوز، الهدف منها هو الوصول لأقل تأخير ممكن (Latency) وأعلى أداء (Performance) في الألعاب والبرامج الثقيلة. 

بدل ما تضيع وقتك في الإعدادات اليدوية، **ARVANEX OS ULTRA** تختصر عليك المشوار بضغطة زر.

---

## 🛠️ وش تقدم لك الأداة؟

### 🏎️ Performance (الأداء)
- تفعيل **Ultimate Power Plan** (خطة الطاقة المخفية).
- تحسين الـ **Kernel** واستجابة النظام للأوامر السريعة.
- إيقاف **VBS** لرفع الفريمات (FPS) في الألعاب.

### 🛡️ Privacy (الخصوصية)
- إبادة خدمات التجسس والـ **Telemetry** نهائياً.
- حذف **Cortana** والمزامنة الخلفية اللي تستهلك مواردك.
- إيقاف تتبع النشاط وسجل الخصوصية في ويندوز.

### 🎮 Gaming & Latency (اللاغ والاستجابة)
- تقليل الـ **Input Lag** للماوس والكيبورد (استجابة 1:1).
- تحسين الشبكة لتقليل الـ **Ping** ومنع تقطيع البيانات.
- تنظيف الـ **Shader Cache** لحل مشاكل الـ Stuttering.

### 🧹 Cleanup (التنظيف)
- حذف الـ **Bloatware** (تطبيقات الويندوز المزعجة).
- تنظيف شامل للملفات المؤقتة وكاش النظام.
